隱私權政策 (Privacy Policy)

最後更新日期：2026 年 8 月 29 日 · SpeedVocab

1. 簡介 (Introduction)

感謝您使用 SpeedVocab（以下簡稱「本應用程式」）。本應用程式為無伺服器（Serverless）架構之純前端單字學習與反應時間測驗工具，致力於保護每位使用者的個人隱私與數據安全。

2. 我們收集與存取的資料 (Information We Collect)

  • Google 帳號基本公開資料：若您選擇使用 Google 登入，系統僅取得您的姓名、電子郵件與公開頭像，僅用於應用程式介面顯示，絕無第三方傳輸。
  • Google Drive 雲端同步資料 (appDataFolder)：本程式嚴格僅申請 https://www.googleapis.com/auth/drive.appdata 權限，僅在您個人的 Google 雲端隱藏專屬目錄存取 vocabulary_data.json 單字進度檔，絕對無法存取您雲端硬碟中的任何其他檔案。
  • 本機測驗數據：包含自訂單字、反應速度（毫秒）、正確率與複習排程，儲存於您本地瀏覽器快取中。

3. 資料使用與絕不外流承諾 (How We Use Information)

所有的記憶演算法與計時皆在您的瀏覽器前端執行。本應用程式沒有後端伺服器，不會將您的資料發送給任何第三方，亦絕不進行任何廣告追蹤或資料販售。

4. Google API 使用者資料政策聲明 (Google API Limited Use)

SpeedVocab 對從 Google API 收到的資訊之使用與傳輸，均嚴格遵守 Google API 服務使用者資料政策 (Google API Services User Data Policy)，包含其中的限定使用（Limited Use）要求。

5. 使用者權利與權限撤銷 (User Rights & Data Deletion)

您隨時可以在應用程式設定中清空本機資料，亦可隨時前往 Google 帳戶安全性設定 隨時撤銷對本應用程式的授權。
